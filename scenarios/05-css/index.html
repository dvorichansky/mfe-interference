05. Каскад стилів (CSS): динамічний відбиток

Модулі вставляють глобальні правила з однаковими селекторами (.btn, .badge) і однаковим токеном --accent. Однакова специфічність означає, що перемагає останнє вставлене правило. Відбиток запису CSS-правила залежить від поточного DOM: правило каталогу .badge { display: none } нічого не робить, доки кошик не створить власний елемент .badge.

    Типи конфліктів: кнопки .btn і токен --accent — запис/запис; бейдж .badge — читання/запис (кошик не задає display). Спробуйте: 1) порівняйте порядки «A, потім B» і «B, потім A» — чиї кнопки «правильні»; 2) у кошику натисніть «Застосувати промокод» і перевірте, чи видно бейдж знижки; 3) увімкніть «Shadow DOM»: селектори ізольовано, але колір кнопок досі спільний, бо кастомні властивості успадковуються крізь межу Shadow DOM; 4) лише «Shadow DOM + префікси токенів» розводить відбитки повністю. Аналог у cau-se: D1 (CSS token collision).
